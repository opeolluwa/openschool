# Saturn

Auth Server over [Echo](https://echo.labstack.com/)

## Description

Extendible authorization server over HTTP written in Golang

## Getting Started

### Dependencies

- [Docker](https://www.docker.com/)
- [Just](https://just.system)
- [Golang](http://go.dev)
- [Git](https://git-scm.com/)

### Installing

```sh
git clone https://github.com/opeolluwa/saturn
cd saturn
just dev
```

## Help

- The database can be viewed at: <http://localhost:8888>
- Email UI available at <http://localhost:1080>
- Redis data <http://localhost:5540>
